# Recorder case and original holder

## Current case: V6.5

The [V6.5 two-piece TPU case](v6.5/README.md) has a flush lid with an internal locating lip, accessible USB/microSD openings, a rear wire exit, and a flat underside for mounting tape. The builder approved the V6.4 printed fit apart from tight port access; V6.5 widens those openings by 0.6 mm overall each. Those final widened openings have not been reprinted.

- [Bottom STL](v6.5/recorder-case-v6.5-bottom-flat.stl)
- [Lid STL](v6.5/recorder-case-v6.5-lid.stl)
- [Editable OpenSCAD source](v6.5/recorder-case-v6.5.scad)
- [Dimensions and verification](v6.5/SPECIFICATIONS.md)
- [Printing, assembly and design contributions](v6.5/README.md)

I'm new to 3D printing, so there's probably a better way to design this case. If you come up with a different or improved design, please submit a pull request! You can also open an issue with ideas, photos, or printable files.

## Original open holder

The earlier `recorder-holder.scad`, `recorder-holder-v2.stl`, and `render-holder*.png` files are retained for reference. They describe the original open tray with underside rails, not the current two-piece case. Do not mix those parts with the V6.5 case. See the repository history for the original holder documentation.
